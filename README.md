# Lumio — AI-Powered Study Platform for STEM Students

> **Study smarter. Not harder.**

Lumio is an AI-powered study platform designed to help STEM students learn more efficiently. It generates personalized flashcards, provides AI-guided quiz practice, and tracks mastery progress — all in one place.

Built as a product design and prototyping project for a Product Management course at Texas State University.

---

## Features

- **Smart Flashcards** — AI Tutor sidebar provides contextual hints, related concepts, and explanations as you study
- **Quiz Mode** — Multiple-choice quizzes with real-time scoring, AI-generated tips, and session stats
- **Upload Your Notes** — Drop in PDF, DOCX, PPTX, or TXT files; Lumio auto-generates flashcards and quiz questions
- **Progress Analytics** — Track XP, cards mastered, quiz averages, study streaks, and mastery by subject
- **Personalized Onboarding** — Users select their subjects (Calculus, Finance, Astronomy, CS, etc.) to personalize the experience
- **Custom Themes** — Background themes including Default, Space, Forest, Sunset, and Ocean
- **Study Preferences** — Toggle daily reminders, sound effects, celebration animations, and AI tutor hints

## Tech Stack

- **Prototype**: HTML / CSS / JavaScript (interactive, browser-based)
- **Design**: Custom dark-mode UI with a STEM-focused aesthetic
- **AI Features**: Designed around LLM-powered flashcard generation, quiz creation, and contextual tutoring

---

## About the Project

Lumio was developed through an iterative product design process including:

- Customer discovery interviews with STEM students
- Persona development and competitive analysis
- Low-fidelity wireframing → high-fidelity interactive prototype
- Usability testing and design iteration

The platform targets a core pain point for STEM students: existing study tools (Quizlet, Anki) are manual and generic. Lumio automates the content creation step and adds AI-guided feedback so students can focus on learning, not setup.
